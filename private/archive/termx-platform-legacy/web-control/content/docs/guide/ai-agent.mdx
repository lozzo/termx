## AI Agent 管理

termx 最适合的场景之一，就是把运行在 TermX 终端里的命令行 AI Agent 搬到移动端继续管理。

### 适合哪些 Agent？

凡是通过命令行交互、能稳定运行在 TermX 终端里的工具，通常都适合接入，例如：

- Claude Code
- OpenCode
- 自定义 shell agent / 脚本 agent
- 其他交互式 CLI 工具

### 推荐工作流

#### 1. 每个 Agent 占一个 TermX 终端或 pane

这样做的好处是：

- 切换清晰
- 不会和普通 shell 混在一起
- 断开移动端后，任务仍能继续跑

#### 2. 在 Web 控制台先配置 Fn 快捷键

当前控制台允许你：

- 覆盖 Claude Code、OpenCode 的默认快捷项
- 增加 `yes` / `no` / `/compact` / `/clear` 之类的高频命令
- 为你自己的 Agent 定义一组新的程序快捷键

这一步能明显减少手机端重复输入。

#### 3. 用片段保存长提示词或固定模板

比如：

- “请先阅读仓库结构再动手”
- “修完后运行测试并总结变更”
- 常用部署脚本或排障命令

#### 4. 用路径收藏快速进入工作目录

如果你的 Agent 主要在固定目录工作，可以先在控制台保存路径收藏，移动端进入节点后就能更快切到目标目录。

### 手机上最常见的几种操作

- 查看 Agent 当前输出是否卡住
- 对权限确认、风险操作进行 `yes` / `no` 决策
- 发送补充提示词或中断命令
- 切换到另一个 pane 查看并行 Agent 的状态
- 在外出时确认长任务是否完成

### 什么时候特别适合用 termx 管 Agent？

- 通勤途中继续盯着代码生成或重构任务
- 夜间让 Agent 跑较长任务，手机上偶尔确认即可
- 运维、日志分析或批处理任务需要人工确认下一步
- 一个项目里同时跑多个不同职责的 Agent

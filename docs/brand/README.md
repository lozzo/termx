# TermX Logo

This logo system is built around the project shape: a remote terminal carried over WebRTC data channels.

- `termx-mark.svg`: square app/icon mark.
- `termx-logo.svg`: horizontal lockup for headers, release pages, and docs.
- `termx-logo-on-dark.svg`: presentation preview with a dark grid background.
- `termx-mark-mono.svg`: one-color fallback for masks, stamps, and tiny uses.

## Concept

The mark combines three ideas:

- a terminal window and prompt shape for the core CLI experience;
- a single-piece X that reads as one product mark instead of separate crossing strokes;
- the X still suggests paired app-agent data paths without fragmenting the shape.

## Palette

- Background: `#09090B`
- Panel: `#18181B`
- Primary green: `#10B981`
- Highlight green: `#34D399`
- Link cyan: `#22D3EE`
- Text: `#F4F4F5`

The palette matches the existing dark TermX web-control theme and keeps emerald as the primary brand signal.

## Usage

Use the square mark when space is tight: favicon, app icon, toolbar button, social avatar.

Use the horizontal lockup when the word `TermX` should be read immediately: landing page header, README, release artifacts, deck title slides.

Keep clear space around the logo equal to at least one quarter of the mark width. On dark surfaces, prefer the full-color SVG. On light or constrained surfaces, use the monochrome mark.

## 常见问题

### 安装与版本

#### 当前提供哪些客户端？

- **本机服务**：Linux / macOS / FreeBSD 可安装；当前提供 `386`、`amd64`、`arm64`，以及 Linux `arm` / `riscv64`
- **移动端**：当前公开发布的是 Android APK
- **iOS**：暂未公开发布

#### 现在还有 `config.yaml` 吗？

没有。termx 现在统一通过 **命令行参数** 和 **环境变量** 配置。

#### 连接密钥应该怎么传？

推荐两种方式：

- 运行 `termx remote enable --mode both`，没有已保存凭据时会自动打开浏览器登录
- 通过环境变量 `TERMX_REMOTE_CONNECTION_KEY`

### 连接与配对

#### 扫码后连接不上怎么办？

按下面顺序检查：

1. 确认目标机器上的 `termx` 仍在运行
2. 如果是 `local` 模式，确认手机与机器网络可达，且监听端口已放通
3. 如果是 云端连接，确认密钥有效、订阅可用、远程节点已成功注册到控制台
4. 运行 `termx remote pair` 生成新的二维码后再次扫码

#### 为什么 App 里节点需要扫码授权？

控制台只负责显示机器注册在哪个 Hub，不保存手机授权状态。首次在 App 打开某台机器时，运行 `termx remote pair`，用 Android 客户端扫描生成的二维码完成本机授权。

#### 删除连接密钥后，已经注册的节点会怎样？

已有节点不会立刻被删除，但这个密钥**不能再用于注册新节点**。如果你删除了节点本身，之后要重新注册，就需要新的密钥。

#### 为什么我能本地直连，但不能远程连接？

通常是以下原因之一：

- 当前本机服务只启用了 local 模式
- 你还没有登录或创建连接密钥，或者没有运行 `termx remote enable --mode both`
- 当前账号没有有效订阅，无法使用 Hub 远程能力

### 账号与订阅

#### 哪些功能需要订阅？

局域网直连和本地使用可以先体验；**创建连接密钥、通过 Hub 远程连接和远程管理节点**需要有效订阅。

#### 忘记密码怎么办？

Web 登录页支持“忘记密码”，系统会向注册邮箱发送 6 位验证码。验证码 10 分钟内有效，输错次数过多需要重新获取。

#### 邀请奖励怎么生效？

被邀请用户完成注册并购买订阅后，邀请人会获得额外订阅奖励天数。你可以在控制台“邀请好友”页面查看已邀请人数和奖励进度。

### 使用体验

#### 支持哪些命令行程序？

只要能在 TermX 终端里正常运行，通常都可以配合 termx 使用，例如：

- shell（bash、zsh、fish）
- 编辑器（vim、nano、emacs）
- AI Agent（Claude Code、OpenCode 等）
- 全屏 TUI（htop、btop、gitui 等）

#### 文件传输是不是一定可用？

文件浏览和传输能力取决于当前客户端能力、连接状态以及账号可用权限。若当前连接路径或账号策略不允许中转文件传输，Android 客户端可能只提供终端能力。

#### 可以同时在多台手机上连接同一个节点吗？

通常可以，但最终体验取决于当前会话、网络和客户端实现。TermX 终端本身是持续存在的，断开移动端后服务端任务也不会停止。

### 安全

#### Hub 会看到我的终端内容吗？

Hub 负责节点发现、连接协调和中转能力，不是用来保存你的终端内容。当前实现里，Hub 连接还会结合用户 JWT、本机服务公钥和配对密钥完成校验与加密链路建立。

#### 本地模式的密码如何处理？

本地模式下如果没有显式传入 `--password`，系统会自动生成并持久化密码；也可以使用 `--no-auth` 关闭本地密码校验，但这只适合可信网络或调试环境。

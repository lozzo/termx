## 订阅、支付与密钥

### 订阅解决什么问题？

当前产品里，“本地局域网直连”和“远程 Hub 能力”是两类不同能力：

- **本地直连**：更适合先体验终端、TermX 远程终端交互
- **Hub 远程能力**：用于跨网络访问、节点云端管理和更稳定的远程连接链路

在当前实现中，**创建连接密钥** 和 **通过 Hub 远程连接节点** 都要求账号拥有有效订阅。

### 套餐与价格

账单页会展示当前可购买的套餐、月付/年付切换和你当前的订阅状态。

为了避免文档和后台配置不同步，**请以控制台账单页面中的实时价格与功能描述为准**。

<Callout type="info">
控制台当前同时支持免费层与 Pro 层的展示逻辑；免费层更偏向本地体验，Hub 远程能力与密钥相关能力由有效订阅解锁。
</Callout>

### 当前支付流程

购买流程如下：

1. 在账单页选择套餐和计费周期
2. 如有优惠码，先在页面内验证
3. 创建订单后进入支付页
4. 当前主流程使用 **微信扫码支付**
5. 支付成功后，订阅状态会自动生效

当前支付页还会展示：

- 订单金额
- 原价与优惠金额
- 套餐功能摘要
- 支付二维码有效倒计时
- 支付成功、失败、超时等状态

### 优惠码

如果你有优惠码，可以在账单页输入后先验证，再决定是否创建订单。

常见限制包括：

- 生效时间 / 过期时间
- 最大使用次数
- 每个用户是否允许重复使用
- 固定金额或百分比折扣

具体是否可用，以页面实时校验结果为准。

### 月付与年付升级

当前逻辑里，系统会阻止明显重复购买，例如：

- 已经是年付用户时，不能再次重复购买年付
- 已经是月付用户时，不能再买一份月付
- 月付用户可以升级到年付

### 连接密钥和订阅的关系

连接密钥是新远程节点注册到你账号下的凭证。它和订阅的关系是：

- **没有有效订阅**：不能创建新的连接密钥
- **已有有效订阅**：可以创建密钥并用它注册节点
- **节点远程连接**：控制台向 Android 客户端和 Hub 下发连接信息时，也会再次校验订阅状态

因此，远程节点工作流通常是：

1. 订阅生效
2. 创建连接密钥
3. 节点注册
4. Android 客户端扫码配对
5. 远程连接

### 订单取消与过期

如果支付页二维码过期，通常需要重新发起支付；你也可以取消当前待支付订单并返回账单页重新下单。

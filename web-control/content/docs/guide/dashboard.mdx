## 控制台与节点管理

Web 控制台是账号、订阅和节点的管理入口。当前面向普通用户的主要页面都在 `/dashboard` 下。

### 账号入口

- **注册**：`/register`，支持通过邀请链接携带 `ref` 参数注册
- **登录**：`/login`
- **找回密码**：`/forgot-password`，通过邮箱验证码重置密码
- **账户设置**：可修改用户名、邮箱和登录密码

### 概览页

概览页会展示：

- 节点总数
- 在线节点数
- 当前订阅状态
- 快捷入口（例如如何添加新节点）

如果当前账号没有订阅，页面会提示升级，以便开启 Hub 远程能力。

### 我的节点

“我的节点”页是最常用的页面之一，支持：

- 查看节点总数、在线、离线、未配对状态
- 按名称、主机名搜索和筛选
- 节点重命名
- 删除节点
- 展开查看启动命令

#### 当前添加节点流程

1. 在“连接密钥”页面创建密钥
2. 在目标机器上运行：`termx remote enable --mode both`
3. 启动守护进程后运行：`termx remote pair`
4. 用 Android 客户端扫码完成配对

> “未配对”表示节点已经注册到你的账号，但手机端还没有完成二维码配对。

### 连接密钥

连接密钥用于给新远程节点注册身份。当前控制台支持：

- 创建密钥
- 选择有效期（30 天、90 天、1 年、长期）
- 复制已有密钥
- 查看每个密钥关联了多少节点
- 删除密钥

重要说明：

- 创建连接密钥需要有效订阅
- 删除密钥不会自动删除已注册的节点，但它不能再用于注册新的节点

### Fn 快捷键配置

控制台中的“快捷键”页用于管理移动端 Fn 面板配置。当前支持三类内容：

- **全局自定义项**：无论当前程序是什么都能显示
- **内置程序预设**：当前内置了 Claude Code、OpenCode 等预设，可隐藏默认项或新增补充项
- **自定义程序**：你可以定义自己的程序匹配规则和快捷键集合

这意味着：

- Android 客户端识别到 `claude`、`opencode` 等命令时，会按你的配置渲染专属快捷键
- 你也可以为内部脚本、私有脚本、自定义 TUI 建一个新的程序面板

### 代码片段与路径收藏

#### 代码片段

适合保存：

- 常用命令
- 多行 shell 片段
- AI Agent 固定提示词
- 重复输入成本高的模板内容

#### 路径收藏

适合保存每台节点上的常用目录，例如：

- 项目根目录
- 日志目录
- 发布目录
- 配置目录

路径收藏当前按节点关联，因此同一个路径可以在不同节点上分别保存。

### 邀请好友

控制台会为每个用户生成专属邀请链接和邀请码。当前页面会展示：

- 已邀请人数
- 已获得奖励天数
- 待发放奖励天数

被邀请用户注册并购买订阅后，邀请奖励会自动累计。

### 管理员页面

如果你的账号是管理员角色，还会额外看到：

- 用户管理
- 订单与订阅管理
- 套餐、优惠码、Hub、版本、节点概览等后台页面

这些页面主要用于运营与平台维护，不是普通用户的日常入口。

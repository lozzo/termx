## 移动端使用

完成扫码后，Android 客户端会根据二维码里携带的连接信息决定如何接入节点：

- 只有本地地址时，优先走局域网连接
- 只有 Hub 信息时，走远程 Hub 连接
- 同时存在本地地址和 Hub 信息时，会优先选择当前更可用的路径

### 节点列表与会话

进入节点后，你可以查看当前机器上的 TermX 终端，并在多个会话、窗口、面板之间切换。

这意味着：

- 手机断开后，TermX 终端仍继续运行
- AI Agent、长任务、编辑器状态都会保留在机器端
- 下次重新连接时，可以从原来的会话继续工作

### 终端操作

移动端终端的核心体验包括：

- 终端输出实时刷新
- 虚拟键盘补齐常用控制键
- 支持 `Ctrl`、`Alt`、`Shift`、方向键、翻页键等高频终端操作
- 适合查看日志、继续 shell 操作、确认 AI Agent 请求

### Fn 面板

Fn 面板会结合两部分信息工作：

1. Android 客户端内置识别当前 pane 里运行的程序
2. Web 控制台中保存的 Fn 配置

因此你可以获得：

- Claude Code、OpenCode 等程序的专属快捷命令
- 自己新增的全局快捷项
- 针对某个自定义程序单独配置的快捷面板

### 命令片段

代码片段页面保存的是“可快速发送到终端的文本片段”。适合：

- 多行 shell 命令
- 环境变量导出
- AI Agent 指令模板
- 日常重复输入的确认文本

### 文件与路径

如果当前连接能力允许，Android 客户端可以配合路径收藏快速进入常用目录，并进行文件浏览或传输。

推荐做法：

- 在控制台先为每台节点保存常用路径
- 在移动端直接跳到项目目录、日志目录或发布目录

### 连接状态

在移动端里，你通常可以看到当前连接类型和状态变化，例如：

- 当前是否走本地路径或 Hub 路径
- 网络抖动后的重连状态
- 远程连接是否仍然可用

### 配对提醒

对于通过控制台注册的远程节点，第一次扫码不仅是“连接”，更是“配对”。配对成功后，客户端会保存该节点所需的安全信息，之后再次连接会更顺畅。
